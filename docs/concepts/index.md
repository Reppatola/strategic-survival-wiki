# Концепты моделей

Рисунки будущих 3D-моделей. Когда модели попадут в Blender — здесь останутся как история.

## Категории

- **Zombies** — walker, sniffer, listener, screamer
- **Player** — игрок, оружие
- **Buildings** — дома, крыши
- **Props** — деревья, ящики, бочки
- **Environment** — земля, дороги

## Статусы

| Статус | Значение |
|---|---|
| 📝 Концепт | Рисунок есть |
| 🎨 Модель | Есть .blend или .glb |
| 🎮 В игре | Интегрирована |
