# Мир

> Мир не является планетой. Это бесконечная фрактальная система,
> где реальность вложена сама в себя.

## Природа мира

Представь пчелиные соты. Каждая сота — огромный регион. Внутри
соты — тысячи ячеек. Внутри ячейки — регионы, государства, области,
агломерации, районы, территории, зоны, точки.

Каждая точка — это чей-то дом, база, аванпост, город.

**Мир растёт.** Игроки могут исследовать его годами и не открыть
даже 10%.

## Причина катастрофы

**Биологическая катастрофа.** Растаяли ледники. То, что было
сковано льдом миллионы лет, вырвалось наружу. Это не вирус в
привычном смысле — это **новая форма жизни**, которая перестроила всё.

## Фрактальная иерархия

Мир строится по строгой вложенной структуре:

| Уровень | Что это |
|---|---|
| **Точка** | Конкретное место. Город, база, аванпост, шахта, порт. |
| **Зона** | Пространство вокруг точки. Здесь работают законы шума. |
| **Территория** | Совокупность зон. Бывает пограничной, опасной, адской. |
| **Район** | Несколько территорий. |
| **Агломерация** | Сотни районов. |
| **Область** | Несколько агломераций. |
| **Государство** | Несколько областей. |
| **Регион** | Несколько государств. |
| **Сота** | Тысячи ячеек. |
| **Ячейка** | Из ячеек собирается весь мир. |

## Гексагональная карта

Карта строится на **гексагональной сетке**. Шестиугольники создают
ровный ромб — базовую единицу масштабирования.

### Структура уровней

| Уровень | Ячеек | Что это в мире |
|---|---|---|
| 1 ячейка | 1 | Точка — база, город, аванпост |
| Малый ромб (7×7) | 49 | Территория |
| Большой ромб (9 малых) | 441 | Район / Агломерация |
| 9 больших | 3 969 | Область |
| 9 областей | 35 721 | Государство |
| 9 государств | 321 489 | Регион |
| 9 регионов | 2 893 401 | Сота |

**Одна сота — 2,9 миллиона ячеек.** Игрок физически не сможет пройти её всю.

## Регионы по уровню опасности

| Тип | Шум | PvP | Зомби |
|---|---|---|---|
| **Безопасный** (столицы фракций) | Не работает | Запрещён | Нет |
| **Условно безопасный** | Слабый | Ограничен | Слабые |
| **Опасный** | Работает | Разрешён | Средние |
| **Адский** | Смертелен | Полный | Максимум |

### Безопасные

Столицы фракций. Единственные места, где:
- Шум не работает
- PvP запрещён
- Смерть невозможна

### Условно безопасные

Пограничные территории. Шум слабый, PvP ограничен.
Здесь живут новички, сюда возвращаются после рейдов.

### Опасные

Земли между фракциями. Шум работает, спавн зомби, PvP разрешён.
Основное поле игры.

### Адские

Ничейные земли. Шум = смерть. Максимальный спавн.
Полный PvP, нет закона. Кто захватил — тот и устанавливает правила.

### Морские регионы

Отдельная механика. Будет описана позже.

## Сезоны

**Зомби-сезон** длится 3 месяца.

Что происходит:
- Зомби растут, становятся опаснее
- Формируются крупные экосистемы
- Растёт агрессия
- Возникают лидеры орд

**В последний день сезона** — массированная атака на одну из
пограничных территорий. Все фракции сплачиваются, отбивают
территорию, получают колоссальные призы.

Затем начинается новый сезон. Правила меняются, но мир остаётся.

## Развитие мира

Мир **растёт**:
- Новые регионы появляются по мере исследования
- Старые меняются под влиянием игроков
- Сезоны меняют правила
- Экономика дышит

Игрок сам выбирает: где жить, с кем, как, когда умереть.
