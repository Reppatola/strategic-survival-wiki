# Словарь

> Единая терминология. Чтобы одну и ту же вещь не называть
> тремя разными именами.

---

## Мир и структура

| Термин | Значение |
|---|---|
| **Ячейка** | Базовая единица мира. Из ячеек собирается всё. |
| **Точка** | Конкретное место внутри ячейки: город, база, аванпост, шахта. |
| **Зона** | Пространство вокруг точки. Здесь работают законы шума. |
| **Территория** | Совокупность зон. Бывает пограничной, опасной, адской. |
| **Район** | Несколько территорий. |
| **Агломерация** | Сотни районов. |
| **Область** | Несколько агломераций. |
| **Государство** | Несколько областей. |
| **Регион** | Несколько государств. |
| **Сота** | Тысячи ячеек. Одна сота — 2,9 млн ячеек. |
| **Малый ромб** | 7×7 = 49 ячеек. Территория. |
| **Большой ромб** | 9 малых = 441 ячейка. Район. |

## Опасность территорий

| Термин | Значение |
|---|---|
| **Безопасная** | Столица фракции. Шум не работает, PvP запрещён, смерть невозможна. |
| **Условно безопасная** | Пограничная. Шум слабый, PvP ограничен. |
| **Опасная** | Земли между фракциями. Шум, спавн, PvP. |
| **Адская** | Ничейные земли. Шум = смерть. Полный PvP. |
| **Морская** | Отдельная механика. Будет описана позже. |

---

## Шум

| Термин | Значение |
|---|---|
| **Шум** | Физическая величина в децибелах (dB). Основной сигнал мира. |
| **База** | Постоянный шум от движения игрока. |
| **Импульс** | Одноразовый источник шума (выстрел, удар, дверь). |
| **Энергетическая сумма** | Формула сложения шума: `LΣ = 10·log10(Σ 10^(Lᵢ/10))`. |
| **Затухание** | Снижение dB со временем: `L(t) = L₀ − k·t`. |
| **Расстояние** | Затухание по расстоянию: `L(d) = L₀ − 20·log10(d)`. |
| **Критический режим** | Шум выше 120 dB. Тревога. |
| **Блокировка территории** | Если шум держится долго — территория закрывается. |
| **Орда** | Собранная масса зомби, идущая на шум. |

---

## Зомби — типы

| Термин | Значение |
|---|---|
| **Обычный** | Балансовый тип. Средние сенсоры. |
| **Слухач** | Слух ×2. Слышит ходьбу с 80 м. |
| **Смотрящий** | Зрение ×3. Видит даже в стелсе. |
| **Нюхач** | Идёт по запаху. Кровь до 50 м. |
| **Слепой** | Экстремальный слух (150 м), без зрения. |
| **Офицер / Элита** | Усиленные сенсоры. Организует орду. |
| **Крикун** | Подтип Офицера. Кричит, собирает орду. |
| **Босс / Улей** | Связь с ордой в радиусе 200 м. |

---

## Зомби — механики

| Термин | Значение |
|---|---|
| **Сенсор** | Один из каналов восприятия: слух, зрение, нюх. |
| **Уверенность** | Накопленный сигнал сенсора. Преодолевает порог — зомби реагирует. |
| **ALERT** | Состояние «замер и поворот к сигналу». Окно среагировать. |
| **SEARCH** | Состояние поиска после потери цели. |
| **CHASE** | Состояние погони. |
| **Зомби-копия** | Копия игрока после его смерти от зомби. |
| **Носитель знания** | Зомби, содержащий данные разведки погибшего игрока. |
| **Сезон зомби** | 3-месячный цикл эволюции и массированной атаки. |

## Фракции и социальное

| Термин | Значение |
|---|---|
| **Фракция** | Одна из 6 основных сил мира. |
| **Столица** | Безопасная зона фракции. Нельзя потерять. |
| **Аванпост** | Форпост фракции. Можно потерять. |
| **Рейдеры** | 3 группировки вне правил. Враг для всех. |
| **Пираты** | 4 группировки по сезонам. Одна активна за раз. |
| **Клан** | Игроки, объединившиеся добровольно. |
| **Альянс** | Объединение кланов. |
| **Корпорация** | Крупное объединение для экономических целей. |
| **Дипломатия** | Отношения между фракциями, кланами, альянсами. |

## Знание

| Термин | Значение |
|---|---|
| **Знание** | Открытая информация о новых территориях. Главный ресурс. |
| **Разведка** | Миссия по открытию новой территории. |
| **Носитель** | Игрок, донёсший знание до города — открывает его для всех. |
| **Открытие территории** | Все фракции получают доступ к новым землям. |
| **Сгоревший прогресс** | Знание, потерянное при смерти от игроков. |
