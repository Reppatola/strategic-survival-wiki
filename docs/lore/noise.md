# Шум

> Шум — это жизнь и смерть мира.

Любое действие игрока создаёт звук. Звук — это сигнал.
Сигнал — это смерть или возможность.

## Шум измеряется в децибелах

Это **физическая величина**, а не абстрактный процент.
Реальная шкала — 0–150 dB (упрощённая игровая).

### Общая шкала слышимости

| dB | Что это | Слышимость |
|---|---|---|
| 0–15 | Шёпот, дыхание | Только в упор |
| 15–30 | Босиком по траве, тихий шаг | 5–10 м |
| 30–45 | Ходьба по земле | 20–30 м |
| 45–60 | Ходьба по гравию, разговор | 50–70 м |
| 60–75 | Ботинки по камню, пила ветки | ~100 м |
| 75–90 | Рубить дерево топором | ~150 м |
| 90–110 | Крик, бензопила | ~300 м |
| 110–130 | Пистолетный выстрел | ~500 м |
| 130–150 | Винтовка, взрыв | 1000+ м |

## Из чего складывается шум игрока

Итоговый шум = **база** (движение) + **модификаторы** (обувь, поверхность)
+ **активные импульсы** (действия).

### База — движение

| Состояние | dB |
|---|---|
| Крадёшься | 30 |
| Идёшь | 50 |
| Бежишь | 70 |

### Модификатор — обувь

| Обувь | Модификатор |
|---|---|
| Босиком | **−15 dB** |
| Тканевые тапочки | −8 dB |
| Кроссовки | −3 dB |
| Ботинки | 0 dB |
| Тяжёлые ботинки | **+5 dB** |
| Бронированная обувь | **+10 dB** |

### Модификатор — поверхность

| Поверхность | Модификатор |
|---|---|
| Трава / снег | **−10 dB** |
| Земля / мох | −5 dB |
| Дерево / доски | 0 dB |
| Бетон / камень | +5 dB |
| Гравий / щебень | **+10 dB** |
| Сломанные ветки / листья | **+15 dB** |
| Металл | **+20 dB** |
| Вода (по луже) | +10 dB |

### Импульсы — действия

| Действие | Импульс |
|---|---|
| Открыть дверь | +15 dB |
| Удар кулаком | +20 dB |
| Разжечь костёр | +30 dB |
| Удар топором | +35 dB |
| Разбить ящик | +40 dB |
| Удар молотком | +45 dB |
| Пила дерева (непрерывно) | +50 dB |
| Выстрел из пистолета | **+110 dB** |
| Выстрел из винтовки | **+130 dB** |

## Формула

итоговый_dB = (база + обувь + поверхность) + активные_импульсы

### Примеры

- **Тихий стелс:** босиком, по траве, крадёшься
  → 30 − 15 − 10 = **5 dB**. Практически неслышно.

- **Обычная ходьба:** кроссовки, по земле
  → 50 − 3 − 5 = **42 dB**. Слышно в ~30 м.

- **Разгром:** бронеботинки, по щебню, бежишь
  → 70 + 10 + 10 = **90 dB**. Слышно в 300+ м.

- **Выстрел:** ходьба 50 dB + пистолет 110 dB = **160 dB**.
  Слышит вся округа.

## Затухание по расстоянию

Формула: `dB_на_расстоянии = dB_источника − 20 × log10(расстояние_в_метрах)`

### Препятствия глушат

| Препятствие | Глушение |
|---|---|
| Стена | −20 dB |
| Дерево | −5 dB |
| Холм | −10 dB |

## Где шум работает

- **Столицы фракций** — шум **не работает**. Единственные
  безопасные зоны в мире.
- **Условно безопасные территории** — угроза слабая.
- **Опасные территории** — угроза серьёзная.
- **Адские территории** — шум = смерть.

## Блокировка территории

Если шум превышает критический порог и держится долго —
**территория закрывается**.

Что происходит:
- Появляется орда с офицерами и боссом
- Спавн идёт с краёв территории
- Блокировка **не снимается**, пока всё живое внутри не умрёт
- Или пока игроки не отсидятся в укреплённой базе
  с запасом еды и прочности стен

## Состояние в коде

**Уже реализовано:**
- База от движения (crouch / walk / sprint)
- Импульсы с энергетической суммой
- Линейное затухание: L(t) = L₀ − k·t
- Затухание с расстоянием: L(d) = L₀ − 20·log10(d)
- Разделение собственного и мирового шума

**Запланировано:**
- Модификаторы обуви
- Модификаторы поверхности
- Глушение через препятствия (стены, деревья, холмы)
- Блокировка территории
- Орда с офицерами и боссом
