# Sniffer


## Откуда

*Заполни. Почему он нюхает след.*

## Внешность

- Приземистый.
- Голова наклонена к земле.
- Большие ноздри.

## Поведение

- Идёт по запаху, даже если игрок тихий.
- Плохое зрение.
- След с ошибкой.

## Тактика

- **Нюх:** 45 м, конус 90°.
- **Слабость:** медленный. Увидишь — успеешь убежать.
