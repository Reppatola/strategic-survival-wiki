# Screamer


## Откуда

*Заполни. Почему он кричит.*

## Внешность

- Раздутое горло.
- Открытый рот.
- Тонкие руки.

## Поведение

- Кричит при виде игрока.
- Крик = 120 dB — слышно на километр.
- Повторяет крик каждые 4 секунды.

## Тактика

- **Убить первым.** Пока жив — собирает орду.
- **HP:** 60. Четыре выстрела.
- **Окно:** ALERT 1.4 сек = длительность крика.
