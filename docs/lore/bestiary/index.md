# Бестиарий

Все типы заражённых. **Лор**, а не характеристики — характеристики в коде.

## Типы

| Тип | Особенность | Опасность |
|---|---|---|
| [Walker](./walker) | Обычный, средний слух и зрение | ★★☆ |
| [Sniffer](./sniffer) | Идёт по запаху | ★★★ |
| [Listener](./listener) | Слышит тихий шум | ★★★ |
| [Screamer](./screamer) | Собирает орду криком | ★★★★ |

## Что важно

- **Silhouette:** тип должен читаться с первого взгляда.
- **Behavior:** поведение объясняется лором, а не «потому что так в коде».
- **Counter:** как игрок должен с ними бороться.
