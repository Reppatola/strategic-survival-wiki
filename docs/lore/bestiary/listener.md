# Listener

![Концепт](/concepts/zombies/listener.png)

## Откуда

*Заполни. Почему у него обострённый слух.*

## Внешность

- Вытянутый.
- Голова набок — прислушивается.
- Характерные наросты (уши).

## Поведение

- Слышит то, что другие не слышат.
- Двигается быстро.
- Не отпускает.

## Тактика

- **Слух:** ×2.5. Слышит ходьбу с 400 м.
- **Слабость:** плохое зрение.
