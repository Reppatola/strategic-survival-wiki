## Принцип работы с этим файлом

1. **Не решай всё сразу.** Вопросы живут годами.
2. **Отмечай решённое.** `[x]` вместо `[ ]`.
3. **Переноси в вики.** Когда вопрос решён — уходит
   на свою страницу, отсюда удаляется.
4. **Добавляй новое.** Каждая новая система рождает вопросы.

**Пустой файл — плохо. Переполненный файл — тоже плохо.**
Здесь должны быть только **живые** вопросы, требующие
внимания в ближайший месяц.
