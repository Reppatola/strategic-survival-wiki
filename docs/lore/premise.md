# Premise

Логлайн игры в 3 предложениях. Главный файл всей вики.

## Формат

> **Когда** [событие], **кто** [герой] **вынужден** [действие],
> **потому что** [причина]. **Но** [препятствие]. **Иначе** [последствие].

## Черновик

*Заполни меня. Одна-две строки. Без воды.*

## Ключевые вопросы

- **Жанр:** survival horror? тактический стелс? экшен?
- **Тон:** мрачный? отчаянный? с чёрным юмором?
- **Длительность:** одна ночь? недели? годы?
- **Одиночный или кооп?**

## Одна фраза — весь смысл

Закончи предложение: *«Эта игра про ______»*.
